### Обязательная процедура проверки перед финальным выбором (30–40 минут)

Выполните **все 8 шагов** для 3 финалистов. Пропуск любого — риск ребрендинга через год.

1. **YouTube:** поиск имени + `youtube.com/@имя` — свободен ли handle
2. **Spotify:** поиск артиста (имя артиста должно быть уникальным для верификации)
3. **Apple Music** + **Amazon Music** + **Deezer** — поиск артиста
4. **Товарные знаки:** USPTO (`tmsearch.uspto.gov`), EUIPO (`euipo.europa.eu`), WIPO Global Brand DB
   — минимум классы **9** (звукозаписи), **41** (развлечения/музыка)
5. **Домен:** `.com` + `.fm` (идеален для музыки) + `.io`
6. **Соцсети:** Instagram, TikTok, X — одинаковый handle
7. **Google:** `"имя"` в кавычках, первые 3 страницы — нет ли крупного бренда
8. **Произношение:** дайте имя прочитать вслух носителю испанского, немецкого и японского.
   Если кто-то запнулся — вычёркивайте.

**Красные флаги — отказывайтесь сразу:**
- Имя занято артистом в любой музыкальной нише (Spotify не даст верификацию)
- Есть TM в классе 9 или 41 в US/EU
- Имя содержит слово, являющееся торговой маркой (Calm, Headspace, Aura, Endel, Pzizz, Tide)
- Имя звучит как существующий крупный канал (Soothing Relaxation, Yellow Brick Cinema,
  Meditative Mind, Greenred Productions, Relaxing White Noise, Calmed By Nature, The Honest Guys)

## ЧАСТЬ 2: ВИЗУАЛЬНАЯ ИДЕНТИЧНОСТЬ

Пример ниже собран под **Quiet Harbour**; при смене имени меняются только слова, система остаётся.

### 2.1 Логотип

**Концепция:** один геометрический символ, читаемый в 16×16 px (favicon) и в 4K.

- **Основная форма:** тонкая линия горизонта + полукруг луны, частично уходящий за линию.
  Ровно 2 элемента. Никаких нот, наушников, облачков, звёздочек, ZZZ.
- **Толщина линии:** 2–3% от высоты знака (тонкая = премиальность)
- **Вариант A (основной):** знак + wordmark справа, для баннера и Spotify
- **Вариант B (компактный):** только знак, для аватара канала и favicon
- **Вариант C (инверсия):** белый знак на тёмном, для превью и оверлеев

**Промт для генерации (используйте в любом image-AI):**
> minimal line-art logo mark, single thin continuous stroke, crescent moon partially
> submerged behind a flat horizon line, perfectly centered, geometric, vector style,
> monochrome warm off-white #F2EDE4 on deep navy #0B1220, generous negative space,
> no text, no gradient, no shadow, flat, 1:1, icon design, extremely simple

### 2.2 Цветовая палитра

Одна палитра для всего бренда. Темы контента различаются **акцентом**, не базой.

| Роль | HEX | Использование |
|---|---|---|
| Base Deep | `#0B1220` | Фон превью, фон видео, тёмная тема |
| Base Mid | `#16243A` | Градиентный переход, второй план |
| Warm Ivory | `#F2EDE4` | Текст, логотип, световые акценты |
| Muted Gold | `#C9A227` | Единственный «дорогой» акцент — луна, огонь, лампа |
| Sleep Indigo | `#3A4E7A` | Акцент серии Sleep |
| Rain Slate | `#5C7A8A` | Акцент серии Rain |
| Forest Moss | `#4A6350` | Акцент серии Nature |
| Ember Rust | `#A85B3C` | Акцент серии Fireplace / Cozy |
| Noise Graphite | `#2E3440` | Акцент серии Brown/Pink Noise |
| Focus Steel | `#546A87` | Акцент серии Focus / Study |

**Жёсткое правило:** ≤3 цвета на одном превью. Насыщенность всегда приглушена —
яркий кислотный цвет мгновенно разрушает ассоциацию со сном.

### 2.3 Типографика

- **Заголовки:** гротеск с широкими межбуквенными пробелами — *Poppins Light*,
  *Jost Light* или *Montserrat Light*. Трекинг +6…+10%. Только это создаёт ощущение «тихо».
- **Подписи/длительность:** тот же шрифт, Medium, размер 45% от заголовка
- **Никогда:** рукописные шрифты, засечки с высоким контрастом, тени, обводки,
  outline-эффекты, градиентный текст
- **Полная поддержка кириллицы, латиницы с диакритикой; для JP/KR — Noto Sans JP/KR Light**

### 2.4 Система превью (Thumbnail System) — главный рычаг CTR

Единая сетка, чтобы зритель узнавал канал в ленте ещё до чтения текста.

```
┌──────────────────────────────────────┐
│                                      │
│        [ЦЕНТРАЛЬНЫЙ ОБЪЕКТ]          │  ← 60% кадра: луна/окно/костёр/волна
│                                      │
│                                      │
│  ────────────────────────────────    │  ← линия горизонта на 62% высоты
│   DEEP SLEEP                     8H  │  ← заголовок слева, длительность справа
│                                      │
└──────────────────────────────────────┘
```

Правила:
1. **Максимум 2 слова** крупным текстом. Не описание — «ярлык серии».
2. **Длительность всегда в правом нижнем углу**, в одном и том же месте, капслоком: `8H`, `3H`, `60M`
3. **Логотип-знак в левом верхнем углу**, 5% ширины, полупрозрачный (60%)
4. **Затемняющий градиент снизу** для читаемости текста
5. **Текст никогда не перекрывает центральный объект**
6. **Проверка на 120 px в ширину** — если не читается, переделывать
7. **Цветовой акцент = серия.** Зритель через 20 видео начнёт узнавать «синие = сон,
   серо-зелёные = природа» без чтения

### 2.5 Стиль анимации в видео

- **Движение:** только очень медленное. Ориентир — **1 полный цикл 45–120 секунд**.
  Быстрое движение = микропробуждения у зрителя = падение retention.
- **Разрешённые движения:** медленный zoom in/out (не более 8% за цикл), параллакс
  облаков, мерцание огня, капли по стеклу, лёгкое покачивание воды, дрейф звёзд,
  плавная смена освещения.
- **Запрещённые:** резкие переходы, вспышки, смена сцены «встык», скорость облаков
  как в timelapse, любые стробоскопические эффекты (риск для светочувствительных зрителей),
  текст, появляющийся в середине видео.
- **Переходы между сценами:** только cross-dissolve длиной 4–8 секунд.
- **Формат «одна сцена на всё видео»** работает для сна лучше, чем смена локаций.
  Смена локаций допустима для focus/study-контента.
- **Loop:** видеоряд зацикливается каждые 3–10 минут; точка склейки должна быть
  в моменте наименьшего движения.

### 2.6 Баннер канала (2560×1440, безопасная зона 1546×423)

Содержимое безопасной зоны:
- Wordmark по центру
- Подстрока: `Sleep · Rain · Ambient · Focus` — четыре слова, разделённые точками
- Фон: горизонтальный градиент Base Deep → Base Mid с еле заметной луной справа
- Никакого расписания загрузок, никаких стрелок «подпишись», никаких иконок соцсетей

### 2.7 Правило консистентности

Каждый раз, когда хочется «сделать поярче, чтобы кликали» — вспомните, что ваш CTR
конкурирует не с новостями, а с другими sleep-каналами. Там выигрывает **спокойствие**,
а не контраст. Единственное исключение — Shorts, где первые 0.5 секунды должны быть
визуально сильными.

### Как превращать статичный кадр в 1–10 часов видео

1. Сгенерировать изображение **в 4K или выше** (важно: апскейл до 3840×2160 обязателен —
   YouTube отдаёт видео 4K с более высоким битрейтом даже тем, кто смотрит в 1080p)
2. Анимировать **20–40 секунд** (image-to-video AI, медленное движение) ИЛИ
   применить медленный Ken Burns-зум в редакторе
3. Собрать **seamless loop** (детали в `04-longform-and-seo.md`, раздел про loops)
4. Повторить луп до нужной длительности, с cross-dissolve на стыках
5. **Не делать 10 видео с одной и той же картинкой** — прямое нарушение inauthentic content
   policy (см. `09-antispam-compliance.md`)
