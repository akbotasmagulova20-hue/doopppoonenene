# 09 — ANTI-SPAM: КАК МАСШТАБИРОВАТЬСЯ, НЕ СТАВ ФАБРИКОЙ

## 0. Почему это самый важный файл

AI-музыкальный sleep-канал — **ровно та категория контента, под которую YouTube
переписал свои монетизационные правила в 2026 году.** Можно сделать всё остальное
идеально и потерять канал на этом.

---

## 1. Что именно изменилось

### 1.1 Inauthentic Content Policy (июль 2026)

**[ПРОВЕРИТЬ ЛИЧНО]:** `support.google.com/youtube/answer/1311392` — страница
«YouTube channel monetization policies». Прямой доступ из среды сборки заблокирован,
данные ниже из вторичных источников (Tubefilter, Social Media Today, отраслевые разборы).

Что известно:

- В июле 2026 YouTube **переименовал** политику **«Repetitious Content» → «Inauthentic Content»**
- 16 июля 2026 опубликовано уточнение, разделяющее немонетизируемый контент на
  **три категории**:
  1. **Generic / template-based content** — шаблонный контент, воспроизводимый в
     масштабе с минимальным человеческим участием
  2. **Unsatisfying or off-putting content** — контент, вызывающий неудовлетворённость
     или отторжение
  3. **AI personas, дающие советы** по чувствительным темам (здоровье, финансы, право)
- Старая политика в основном ловила **буквально повторяющиеся загрузки**;
  новая нацелена на **контент, лишённый подлинного человеческого творчества**
- **AI-контент НЕ запрещён.** Видео, созданные с помощью AI, остаются полностью
  монетизируемыми, если добавляют оригинальную ценность: авторский подход,
  повествование, исследование, отчётливую человеческую перспективу
- Политика **reused content** (чужой контент, компиляции, реакции) не менялась

### 1.2 Что это значит конкретно для sleep-канала

**Опасная зона (высокий риск попадания под политику):**
- ⛔ Один и тот же аудиотрек, залитый N раз с разными картинками
- ⛔ Одна и та же картинка с разными треками
- ⛔ Тридцатисекундный луп, механически растянутый на 10 часов без вариации
- ⛔ Серия видео, отличающихся только цифрой в заголовке («Sleep Music 1», «Sleep Music 2»…)
  при идентичном содержании
- ⛔ Превью, отличающиеся только текстом
- ⛔ Метаданные, сгенерированные по единому шаблону без изменений
- ⛔ Автопубликация 5+ видео в день
- ⛔ Чистый необработанный вывод генератора, залитый как есть

**Безопасная зона:**
- ✅ Каждое видео — уникальная музыкальная композиция (уникальный набор генераций,
  уникальная аранжировка, уникальное сведение)
- ✅ Каждое видео — уникальный визуал
- ✅ Заметная человеческая работа: подбор, структурирование, сведение, мастеринг,
  дизайн превью, написание описаний
- ✅ Оригинальное позиционирование и узнаваемый авторский стиль
- ✅ Разумный темп публикации

## 2. ЧЕТЫРЕ УРОВНЯ ЗАЩИТЫ

### Уровень 1: Уникальность на входе (обязательный минимум)

Для **каждого** видео должно выполняться **всё**:

| Требование | Проверка |
|---|---|
| Уникальный набор из ≥6 музыкальных генераций | Никакая генерация не использовалась в другом опубликованном видео |
| Уникальный визуальный материал | Никакой кадр/анимация не повторяется в другом видео |
| Уникальная структура композиции | Разный порядок блоков, разная длина кроссфейдов, разная динамическая кривая |
| Уникальное превью | Разный кадр, не только разный текст |
| Уникальное описание | Минимум 60% текста отличается; не шаблон с подстановкой одного слова |
| Обработка применена | Все 7 шагов пост-процессинга из `06` |

### Уровень 2: Видимый человеческий вклад

Это то, что **проверяющий человек** увидит, открыв канал:

1. **Оригинальный бренд** — логотип, палитра, типографика, единая система превью
2. **Кураторские плейлисты** с написанными вручную описаниями
3. **Закреплённые комментарии**, ответы зрителям, реальное присутствие
4. **Раздел «О канале»** с рассказом о том, кто вы и как создаёте музыку
5. **Заявление об оригинальности в описании каждого видео** (шаблон ниже)
6. **Раскрытие использования AI** — честное, не спрятанное
7. **Вариативность** контента между видео, видимая с первого взгляда

**Шаблон заявления для описания:**
```
All music on this channel is original, composed and produced for [BRAND].
Each track is generated with AI tools, then selected, arranged, layered,
mixed and mastered by [ВАШЕ ИМЯ] into a continuous long-form composition.
Visuals are original AI-generated artwork, animated and edited in house.
```

### Уровень 3: Ритм и разнообразие публикации

| Правило | Значение | Почему |
|---|---|---|
| Максимум long-form в день | **1** | 3+ видео/день — паттерн фабрики |
| Максимум long-form в неделю | **4–5** | Выше — трудно доказать ручной вклад |
| Максимум Shorts в день | **3** | Выше — риск восприятия как спам |
| Минимальный интервал между публикациями | **4+ часов** | Не публиковать пачкой |
| Подряд видео одной категории | **максимум 2** | Чередовать Rain → Sleep → Focus → Nature |
| Доля «экспериментальной» категории | **≥10%** | Доказательство творческого поиска |
| Одинаковая длительность подряд | **максимум 2** | Чередовать 3ч / 8ч / 1ч |

**Никакой автопубликации по расписанию без проверки.** Каждое видео публикуется
осознанно, с финальным просмотром.

### Уровень 4: Долгосрочная дифференциация

Через 6 месяцев на канале должно появиться что-то, чего **нельзя воспроизвести
скриптом**:

- **Собственные полевые записи.** Запишите реальный дождь, реальный костёр, реальный
  ручей на телефон или рекордер. Даже 20% собственного материала радикально меняют
  статус канала. Это самый сильный и самый дешёвый ход в этом списке.
- **Серия с авторской концепцией** («One Window, Four Seasons», «Sounds of an Empty City»)
- **Взаимодействие с аудиторией:** видео по запросам зрителей из комментариев
- **Livestream** — живое присутствие
- **Авторский текст**: короткие заметки о том, как создавалась композиция
- **Собственная фотография/видеосъёмка** вместо части AI-визуала

## 3. ЧЕК-ЛИСТ ПЕРЕД КАЖДОЙ ПУБЛИКАЦИЕЙ

```
МУЗЫКА
[ ] Композиция собрана минимум из 6 уникальных генераций
[ ] Ни одна генерация не использовалась в другом опубликованном видео
[ ] Применены EQ, компрессия, общий reverb, мастеринг −14 LUFS
[ ] Порядок блоков отличается от предыдущих видео
[ ] Fade-in 15с, fade-out 60–90с, нет резкого обрыва
[ ] Промт не содержал имён артистов, групп, песен, лейблов

ВИЗУАЛ
[ ] Визуальный материал не использовался ранее
[ ] Движение медленное, нет вспышек и стробоскопа
[ ] Разрешение 4K, точки склейки лупа не заметны на 4× скорости

УПАКОВКА
[ ] Превью уникальное (не только текст)
[ ] Превью читается на ширине 120 px
[ ] Заголовок не кликбейтный, соответствует содержимому
[ ] Описание уникально минимум на 60%
[ ] Есть заявление об оригинальности
[ ] Есть дисклеймер об отсутствии медицинских обещаний
[ ] Нет «стены ключевых слов»
[ ] ≤5 хэштегов

ПОЛИТИКИ
[ ] Нет медицинских заявлений («лечит», «вылечит», «гарантированно»)
[ ] Нет упоминаний брендов-конкурентов в заголовке
[ ] Нет ложных обещаний в превью
[ ] Указано «Altered or synthetic content», если это требуется формой YouTube
    для реалистичного AI-контента
[ ] Это не 3-я публикация за сегодня
[ ] Предыдущее видео было другой категории
```

## 4. РАСКРЫТИЕ ИСПОЛЬЗОВАНИЯ AI

**[ПРОВЕРИТЬ]:** YouTube требует помечать **реалистичный** синтетический контент
(в форме загрузки есть раздел «Altered or synthetic content»). Формально музыка
и абстрактные визуалы обычно не подпадают под требование — оно нацелено на
реалистичные изображения людей, событий и мест.

**Рекомендация всё равно раскрывать добровольно в описании.** Причины:
1. Доверие аудитории — скрытое AI, вскрытое зрителями, наносит больший урон,
   чем честное раскрытие
2. Демонстрация добросовестности при возможной ручной проверке
3. Требования стримингов (Spotify использует DDEX-раскрытие) — единый подход проще

**Формулировка, которая работает:**
> Created with AI-assisted composition, then arranged, mixed and mastered by hand.

Не «100% AI», не «без AI» — оба варианта хуже честной формулировки.

## 5. ЧТО ДЕЛАТЬ, ЕСЛИ МОНЕТИЗАЦИЮ ОТКЛОНИЛИ

1. **Не паниковать и не удалять видео.** Удаление не улучшает ситуацию.
2. **Прочитать точную причину** в YouTube Studio — политика называется конкретно.
3. **Если причина — inauthentic content:**
   - Провести аудит: найти видео с наибольшим сходством между собой, **сделать
     их приватными** (не удалять)
   - Переписать описания, добавить заявления об оригинальности
   - Переделать повторяющиеся превью
   - Добавить 5–10 заметно отличающихся видео с очевидным человеческим вкладом
     (включая полевые записи)
   - Обновить «О канале»
   - **Ждать 30 дней** перед повторной подачей (раньше нельзя)
4. **Если причина — reused content:** проверить, не использовали ли вы чужие
   полевые записи или стоковые видео без прав
5. **Апелляция:** приложить доказательства ручной работы — скриншоты проектов
   в редакторе, исходные генерации, историю работы

## 6. ДОПОЛНИТЕЛЬНЫЕ РИСКИ, О КОТОРЫХ ЧАСТО ЗАБЫВАЮТ

| Риск | Описание | Митигация |
|---|---|---|
| **Content ID на собственные треки** | Дистрибуция на стриминги с включённым Content ID → претензии на ваш же канал | Отключать Content ID для треков, уже опубликованных на YouTube |
| **Ложные претензии на полевые записи** | Кто-то зарегистрировал в Content ID шум дождя | Использовать только собственные записи или записи с чистой лицензией (Freesound CC0, собственные). Оспаривать претензии с доказательствами |
| **Стоковые видео без прав** | Скачанный «бесплатный» футаж может быть защищён | Использовать только собственный AI-визуал или лицензированный сток с сохранёнными лицензиями |
| **Название канала = чужой товарный знак** | Ребрендинг через год стоит дорого | Полная проверка по процедуре из `02` |
| **Medical misinformation** | Заявления о лечении | Дисклеймер + формулировки из `06` |
| **Жалобы на фотосенситивность** | Мерцание, стробоскоп | Полный запрет резких изменений яркости |
| **Смена политики** | Правила меняются | Перечитывать политики монетизации раз в квартал |

## 7. ФИЛОСОФИЯ МАСШТАБИРОВАНИЯ

Ключевой вопрос, который стоит задавать себе перед каждым видео:

> **«Если человек из команды YouTube откроет мой канал и посмотрит 10 видео подряд,
> увидит ли он работу автора — или конвейер?»**

Масштабирование в этой нише достигается **не количеством видео в день**, а:
- **Многократным использованием одного производственного усилия**
  (одна фотосессия локации → 4 разных видео разных длительностей и разных музыкальных миров)
- **Локализацией** (одно видео = доступ к 9 рынкам вместо одного)
- **Плейлистами и сериями** (существующий контент работает дольше)
- **Вечнозелёностью** (поисковое видео приносит просмотры 3 года)

Это и есть «масштабирование без пропорционального увеличения ручной работы» —
не больше видео, а больше отдачи с каждого.
